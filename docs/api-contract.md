# API contract v1.0

`POST /v1/analyze` requires `Authorization: Bearer <AGENT_API_KEY>` and `Content-Type: application/json`. No browser CORS is enabled. This is a Laravel-to-service interface.

```json
{
  "document_id": "doc-123",
  "content": {
    "language": "sk",
    "pages": [{"page": 1, "text": "FAKTÚRA č. FA-001\nSuma spolu: 120,00 EUR"}],
    "sheets": []
  },
  "form": {"id": "bbsk_11824", "schema": null, "mapping_id": "bbsk_11824_default"},
  "options": {"include_unmapped": true}
}
```

All typed envelopes forbid extra properties. Document/form/mapping IDs use ASCII letters, numbers, `_` and `-`, maximum 100 characters. Use opaque non-personal document references. Pages preserve positive source page numbers, including non-contiguous indices. A single unpaginated export uses `page:null`; it cannot be mixed with numbered pages. Duplicate page IDs, sheet names, rows or cell coordinates are rejected. At least one non-whitespace page or nonempty cell is required.

Structured Excel example:

```json
{
  "document_id": "excel-1",
  "content": {
    "pages": [],
    "sheets": [{"name": "Doklad", "rows": [
      {"row": 2, "cells": [
        {"coordinate": "A2", "value": "Suma spolu"},
        {"coordinate": "B2", "value": 120.5}
      ]}
    ]}]
  }
}
```

Cells carry string, number or null values, plus optional `formula` and `header_cells` (up to eight source coordinates). The XLSX helper preserves formulas as text with null values. Supplied formula cells cannot be direct evidence. Evidence for B2 is `{"page":null,"quote":"120.5","locator":{"sheet":"Doklad","cell":"B2","context_cells":["A2"]}}`. Context must be in the same row or above the value in its column. No source coordinates are renumbered.

Form resolution: without `form.mapping`, an explicit `form.schema` takes precedence over the configured template and `id` must match the registered `mapping_id`. With optional inline `form.mapping`, its `id` and `form_id` must match the envelope. A previously unknown form requires its authoritative schema; a known form may reuse its configured schema. Inline rules are validated before provider execution and are never persisted. The new `version` is an optional mapping audit label. No paths, expressions, provider settings or credentials are accepted in mapping JSON. See [dynamic mapping](egrant-mapping.md).

This route authenticates a trusted Laravel service, not individual form administrators. Laravel must check tenant permissions, choose current authoritative schema/mapping versions, and keep the token away from browsers. Omitting `form` returns universal extraction with a no-mapping warning.

`content.language` accepts two-letter language hints and supported OCR aliases (`slk`, `eng`, `ces`, `cze`, `deu`, `hun`, `pol`, `ukr`, `fra`). Outer/component whitespace and case are normalized, aliases become two-letter codes, duplicate codes are removed, up to five `+`-separated codes are accepted. Empty components, unknown three-letter aliases, punctuation and oversized lists are rejected. Existing `sk` remains valid. Language is a hint, never evidence for currency.

The response contains `document_id`, `status="completed"`, `document_type`, React-compatible `fields`, `tables`, `warnings`, `requires_review=true`, `extracted_data`, `meta`. It does **not** contain `document`. Laravel adds that stored summary. Table tags are full paths; cell tags are short child tags. Selects use React `string`. No attachment values are suggested. The actual [mock response](examples/mock_response.json) and [OpenAPI snapshot](examples/openapi.json) are generated by the smoke test.

`extracted_data` has fixed universal `fields`, `classification`, `line_items`, and bank `transactions`. Contract-specific facts include number, subject, date and amount. Each fact carries value/status/evidence/confidence/source_kind, additive `validation_reasons`, and optional `currency` metadata containing value/status/evidence/reasons. Currency metadata is recomputed from sources; provider-supplied metadata is not trusted. Decimal amounts are strings in this richer representation to preserve decimal precision; React boundary values are JSON numbers. Dates use ISO `YYYY-MM-DD`. `include_unmapped=false` sets the entire richer `extracted_data` payload to null; it never removes warnings or mapped suggestions.

Rejected classifications retain `null/not_found/0` and now include a server-generated reason in `classification.validation_reasons` and a fixed warning containing the same code. These diagnostics distinguish a missing proposal, invalid type, source mismatch and unsupported heading without returning rejected values. They remain available in warnings when `include_unmapped=false`. See [classification diagnostics](classification-diagnostics.md) for the codes and limitations. A disagreement between a grounded classification and the proposed top-level type is marked `needs_review`; the response type stays `unknown` and mapping remains blocked.

`verified` means deterministic evidence, meaning and applicable format checks passed; it does not mean accounting approval or proof that OCR itself is correct. `needs_review` values remain in the universal payload with capped confidence and reasons. The mapper also preserves safe suggestions when role/format checks support them (for example, provider uncertainty about an otherwise grounded description). Invalid format, role conflicts, conflicting values, arithmetic conflicts or protected destinations prevent suggestions. Sensitive dates/amounts/identifiers require a supported role. A currency-restricted target additionally needs a verified matching currency. The server makes this decision using private validation state, not provider flags. Mapped fields retain all original React keys and add `status`, `validation_reasons`, `source_locator`; consumers may ignore them. Missing or rejected facts have null/0/not_found/no evidence. The original document stays with Laravel.

## Limits and errors

Default configurable limits: 2,000,000 body bytes; 150,000 content characters; 50 pages; 10 sheets; 2,000 rows total; 10,000 cells; 5,000 form nodes; form depth 20. Hard model ceilings protect excessively permissive configuration. Body receipt timeout is 10 seconds. Compressed bodies are rejected. Page and cell text count towards content limits; the entire schema counts towards the body limit.

Errors consistently have `{"error":{"code":"...","message":"safe Slovak text","request_id":"UUID"}}`. They never echo invalid input or provider response bodies. Responses include `X-Request-ID` and `Cache-Control: no-store`. A valid supplied UUID correlation ID is retained; other IDs are replaced.

| Status | Typical code |
|---|---|
| 401 | `auth_missing`, `auth_invalid` |
| 408 | `request_timeout` |
| 413 | `request_too_large`, `content_too_large`, `workbook_too_large` |
| 415 | `unsupported_media_type`, `unsupported_encoding` |
| 422 | `invalid_request`, `unknown_mapping`, `invalid_form_schema`, `invalid_mapping_destination`, `invalid_select_mapping`, `protected_mapping_destination`, `reserved_mapping_destination`, `invalid_mapping_type`, `mapping_identity_mismatch`, `missing_form_schema`, `invalid_workbook`, `empty_workbook`, `unsupported_workbook_features` |
| 429 | `busy` |
| 500 | `internal_error` |
| 502 | `provider_invalid_output`, `provider_rejected_request`, `provider_auth_error`, `provider_unsupported_mode` |
| 503 | `not_ready`, `provider_unavailable`, `provider_rate_limited`, `provider_configuration_error` |
| 504 | `provider_timeout`, `analysis_timeout`, `workbook_timeout` |

`GET /health`, `/ready`, `/version`, `/docs`, `/openapi.json` are unauthenticated and contain no keys. Production ingress may restrict documentation separately. Readiness never calls a model.


## XLSX preparation

`POST /v1/prepare-xlsx` requires the same Bearer token and raw XLSX bytes with `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` (not multipart). It returns `{"content": {"language":"sk","pages":[],"sheets":[...]}, "warnings":[...]}`. See [saved preparation](examples/prepared_xlsx.json) and [subsequent analysis](examples/xlsx_response.json). The endpoint does not invoke any model.

```sh
curl -X POST http://127.0.0.1:8001/v1/prepare-xlsx \
  -H "Authorization: Bearer $AGENT_API_KEY" \
  -H "Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet" \
  --data-binary @synthetic.xlsx
```

Defaults: 5 MB compressed input, 20 MB expanded ZIP, 200 ZIP entries, compression ratio 200, 150,000 XML nodes, two concurrent parsers, 15-second preparation deadline. The ordinary sheet/row/cell/text limits also apply. Nonempty cells retain original sheet/row/coordinate; Excel date cells become ISO dates. Known semantic labels associate same-row values or values below their column; header cells never become data candidates merely because another header precedes them. This is a conservative relationship hint, validated again as evidence.

Formulas are returned as text with null values and never evaluated. Empty sheets survive within a workbook containing values; an entirely empty/formula-only workbook returns `empty_workbook`. Macros, embedded objects and external relationships are rejected. Oversized, encrypted, duplicate-entry, malformed XML/ZIP and inconsistent-dimension archives fail safely. Parser threads remain counted against concurrency after caller cancellation until they finish; their bounded work is drained at shutdown. Laravel still owns upload validation, storage, splitting multi-document registers and user confirmation.
